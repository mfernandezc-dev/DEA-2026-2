Los originales privados siguen conservados solo en la máquina de desarrollo y están excluidos por `.gitignore`. Las copias públicas omiten rutas locales; no convierten una exportación o captura en una nueva ejecución del laboratorio.

Para ejecutar el proyecto en una instalación nueva, seguir el README de la raíz del laboratorio. Las herramientas de `herramientas/` son auxiliares históricos: algunas requieren generar primero los artefactos locales y respaldos de su propia ejecución. No ejecutar restauraciones sobre una base con datos personales.
